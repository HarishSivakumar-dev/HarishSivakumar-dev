### 🎟️ [01] TICK-IT
`Enterprise Microservices Ticket Management & Grievance Platform`

```ini
[STATUS] Deployed & Operational
[STACK ] Spring Boot | Eureka | Config Server | API Gateway | JWT | OAuth2 | Redis | OpenFeign | WebSockets | Kafka
```
* **Microservices Ecosystem**: Engineered decoupled Spring Boot services registered with **Eureka Service Discovery** and routed via **Spring Cloud Gateway**.
* **Distributed Rate Limiting & Cache**: Integrated **Redis with custom Lua scripts** for atomic rate limiting to guarantee high-throughput stability.
* **Security & Auth**: Secured endpoints via **JWT Stateless Authentication & Google OAuth2** with role-based access control (RBAC).
* **Inter-Service Communication**: Leveraged **OpenFeign** for synchronous microservice RPCs and **STOMP WebSockets** for real-time notifications with a Kafka-ready architecture.
